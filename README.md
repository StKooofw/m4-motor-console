# MSPM0G3507 四路电机控制台

这是 MSPM0G3507 四路闭环电机控制板的桌面网页上位机。在线地址：

<https://stkooofw.github.io/m4-motor-console/>

页面通过浏览器 Web Serial 直接连接电脑上的 USB-UART 适配器，提供四路实时状态、编码器/速度/占空比波形、开环与速度闭环控制、参数管理、急停、CSV 导出和 UART 应用固件升级。页面没有演示模式；没有连接真实控制板时不会生成虚拟波形或虚拟设备状态。

## 使用要求

- Windows 桌面版 Chrome 或 Edge，使用支持 Web Serial 的较新版本。
- USB-UART 适配器使用 3.3 V 电平，并与控制板共地。
- 控制板 UART 为 115200-8-N-1；适配器 TX/RX 必须与控制板 RX/TX 交叉连接。
- 首次点击“连接设备”时，需要在浏览器串口选择器中授权对应的 USB-UART 设备。

网页托管在 HTTPS 下，满足 Web Serial 的安全上下文要求。串口数据只在浏览器与本机串口之间流动，页面不会把遥测、参数、固件或更新密钥上传到服务器。

## 固件升级

升级页需要同时选择两个本地文件：

- `application_update.bin`：带控制板 ID、版本、向量和 CRC 的应用升级包。
- `m4_update_key.bin`：32 字节二级 BSL 更新密钥。

更新密钥不在本公共仓库中，也不会写入浏览器存储。它只在当前页面内存中用于本地 UART 解锁。首次烧录映像、NONMAIN 配置、应用升级包和更新密钥由固件工程的本机私有发布目录单独管理，不应上传到公开仓库。

正常升级时先连接设备，再进入“固件升级”页选择两个文件。页面会校验镜像、锁定控制、发送急停、进入二级 BSL、写入应用区、校验目标 CRC，然后重启并核对版本。应用损坏或升级中断时，重新上电后可用“恢复模式写入”选择同一串口重试。

## 本地开发

不要直接双击 `index.html`。在本目录启动静态 HTTP 服务，再用 Chrome 或 Edge 打开本机地址：

```powershell
python .\serve_web.py --port 8765
```

然后访问 <http://127.0.0.1:8765/>。`serve_web.py` 只负责给 JavaScript 模块返回正确的 MIME 类型；仓库不依赖前端构建工具，GitHub Pages 发布内容仍是浏览器直接加载的 HTML、CSS 和 JavaScript 模块。

## 发布边界

本仓库只发布静态上位机，不包含任何 MSPM0G3507 可烧录映像、XDS110 恢复文件、NONMAIN 配置、BSL 密钥或真实板卡日志。网页协议和升级逻辑已经过主机自动测试，UART BSL 核心已在当前控制板上完成实机升级验证；电机方向、编码器极性、带载闭环和整机电磁兼容仍需在具体硬件上验证。
