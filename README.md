# K230 / MSPM0G3507 多产品控制台

这是 K230 与 MSPM0G3507 控制产品的统一桌面网页入口。在线地址：

<https://stkooofw.github.io/m4-motor-console/>

首页只负责选择产品，三个工作台彼此独立：

- `CM4M`：四路闭环电机驱动板，提供 A/B/C/D 通道控制、速度环整定和专属 UART 固件升级。
- `CHAS`：双轮灰度循迹底盘，左右轮可从 A/B/C/D 中选择任意两个不同通道，灰度黑线电平可反相，并提供 16 路灰度、ICM45686 六轴姿态/波形、循迹/航向参数、角度环标定和专属 UART 固件升级。
- `BBK230`：车载平衡滚球闭环，网页通过独立 3.3 V USB-UART 连接 K230；同一工作台还可通过第二条 Web Serial 直接连接 QDrive Type-C，读取状态、调参、绘制波形和执行本地 WebUSB DFU。

三个产品使用独立设备身份、命令和状态。CM4M/CHAS 共享经过验证的二进制外层帧和 TI 二级 BSL 客户端，但升级板型 ID 不同；BBK230 的 K230 链路使用带 `product="BBK230"` 与请求序号的 UTF-8 NDJSON，QDrive Type-C 链路使用设备自身 LetterShell。网页不提供 K230 固件升级；QDrive DFU 只读取用户本地选择的 `.dfu`，不会托管固件文件。连接错设备或选择错升级包时，网页会拒绝继续。页面没有演示模式；没有连接真实设备时不会生成虚拟遥测。

CHAS 的“标定”页还可同时打开第二个 `115200-8-N-1` Web Serial 端口连接无线串口适配器。
CHAS v1.0.24 起，这个低流量控制台除静态零偏、角度标定、中止和急停外，还可用独立一次性
令牌启动灰度循迹，并读取/修改行驶参数、灰度位置 PID 和航向角 PID。运行期间页面每
200 ms 发送静默续租，固件在 600 ms 内未收到续租就安全停车；参数先写 RAM，只有明确点击
“保存到 Flash”才持久化。无线口不接收全量 IMU 波形，也不提供直接轮速、解除急停、CM4M
单轮速度 PID 或固件升级入口。角度标定和发车分别使用独立令牌，均不能由网页跳过确认。

CHAS v1.0.18 起，“角度环自动标定”会显示三档正反差速辨识和正反
`30/60/90 deg` 阶跃的 12 段进度，同时显示等效轮距、双向增益差、最坏超调、
最坏稳定时间和 CM4M 实际轮速/故障反馈。旧固件不具备这些验证条件，网页会禁用
角度标定入口并提示先升级；候选参数只有全部阶跃通过后才可应用，网页不会自动保存 Flash。

CHAS v1.0.22 起，无线口还会以不高于 2 Hz 返回差速模型、候选 PID、阶跃目标、
车体航向、Z 轴角速度和左右轮目标/实速。标定页会将这些数据整理成独立的 12 段状态条、
模型与实时数值，而不是只显示原始终端文本；连接无线口后会先自动读取只读状态，只有
`READY=07`、静态零偏完成和三项机械确认同时满足时才允许预备角度标定。固件的一次性
令牌和网页“确认启动”按钮仍是不可跳过的第二步，失败或无线断开不会自动应用候选参数。

CHAS v1.0.28 起，无线状态会追加灰度 `RAW/ACTIVE/COUNT/POLARITY` 和位置判定，发车失败
直接显示未检线、有效路数过多、IMU 未标定、模块未就绪或底盘状态错误。标定页可显式
启停 5 Hz 行车诊断流，显示航向/参考航向、Z 轴角速度、差速和左右轮目标/实速；也可在
停车时修改灰度黑线有效电平。周期诊断默认关闭，参数仍只写 RAM，点击保存后才写 Flash。

在四路电机工作台中，选择通道和模式、输入目标后点击“发送目标”即可启动该路；取消使能或点击“停止本路”会立即禁用该路。底盘工作台具有独立的运行开关、双轮手动控制与急停。保持网页连接时状态轮询维持通信，关闭页面、断开串口或链路超时后仍由对应产品固件安全停机。

CHAS v1.0.4 及以上支持同端口电机透传：在四路电机工作台选择连接到底盘主控的
CH340 后，页面会自动识别底盘、请求安全停止并切换到电机板协议，无需更换串口。
透传覆盖四通道独立控制、参数整定/保存和电机板 UART 固件升级；旧版 CHAS 会被
明确拒绝并提示先升级底盘固件。

三个产品页面同时打开时，手动连接会通知其他页面先安全停机并释放串口；升级、
自动整定或滚球有限回合期间不会抢占。由电机透传切回底盘时，页面会等待固件的空闲回切
完成后再识别 CHAS，避免重复打开同一个 Web Serial 端口。所有页面都不会在加载时自动打开
已授权串口，串口所有权只由明确点击连接按钮获得。

## 使用要求

- Windows 桌面版 Chrome 或 Edge，使用支持 Web Serial 的较新版本。
- USB-UART 适配器使用 3.3 V 电平，并与控制板共地。
- 控制板 UART 为 115200-8-N-1；适配器 TX/RX 必须与控制板 RX/TX 交叉连接。
- BBK230 的 K230 链路接 UART1，K230 UART2 单独连接 QD4310；网页可同时打开 QDrive Type-C 的 USB CDC LetterShell。两套解析器与串口会话彼此独立，K230 已武装时网页禁止 QDrive 直控和改参。
- QDrive 直接控制只对 `config --list` 明确返回 `timeout` 且当前值大于 `0 s` 的固件开放。本机 6.2.2 固件未提供该参数，因此可读取、终端诊断和调参，但网页会禁止直接使能/控制，直到 QDrive 固件补齐通信超时停机。
- 首次点击“连接设备”时，需要在浏览器串口选择器中授权对应的 USB-UART 设备。

网页托管在 HTTPS 下，满足 Web Serial 的安全上下文要求。串口数据只在浏览器与本机串口之间流动，页面不会把遥测、参数或固件上传到服务器。

## 固件升级

升级页只需选择对应产品生成的 `application_update.bin`。CM4M 页面只接受 CM4M 板型，CHAS 页面只接受 CHAS 板型；两边都会校验版本、分区、向量和 CRC，不需要再选择单独的密钥文件。

网页协议客户端内置 TI 二级 BSL 命令所需的固定兼容字段，因此这套机制不提供密钥安全保护。首次烧录映像、NONMAIN 配置和应用升级包由固件工程的本机私有发布目录单独管理，不应上传到公开仓库。

正常升级时先连接设备，再进入“固件升级”页选择应用 BIN。页面会校验镜像、锁定控制、发送急停、进入二级 BSL、写入应用区、校验目标 CRC，然后重启并核对版本。应用损坏或升级中断时，重新上电后可用“恢复模式写入”选择同一串口重试。

## 自动闭环整定

在“参数设置”中选择通道，确认轮子架空、编码器尺度有效，并明确机械方向状态后，可启动自动整定。页面会备份参数并停止四路，随后仅让所选通道依次执行 10%、15%、20% 开环阶跃，辨识电机增益、死区、时间常数和延迟，自动统一编码器反馈符号并计算保守 PI。最后用 10 至 30 rpm 的目标做 4 秒闭环验收；平均误差、超调、饱和、振荡或编码器跳变任一项不合格都不会保存。

只有整定和闭环验收全部通过才写入参数 Flash。整定中使用的 20% 占空比和 `100 mrpm/tick` 只存在于临时 RAM 参数：保存前会恢复开始整定前该通道的“最大占空比”和“加速度斜坡”，仅保留本次辨识得到的 PI、反馈方向等结果。任何异常或点击“立即停止”都会锁存急停、禁用四路并恢复开始前的 RAM 参数。

整定后的 JSON 报告包含原参数、20% 临时候选参数、最终保存参数、开环摘要、闭环指标和 50 ms 遥测样本。旧版网页已经把某路保存成 20% 时，修复不会擅自提高该路功率：选择该路，在“最大占空比”中填写希望的运行上限（例如先从 60% 开始），点击“保存参数”，随后再逐级验证高速与带载。20% 的整定数据不能证明高占空比、带载或四路同时运行稳定。

当前硬件只有 A/B 相，没有 Z 相或外部真实转速基准，因此开环自转无法凭空反推出绝对 CPR 或减速比；这两个值必须先按编码器规格填写，或由独立转速基准测得。

网页使用 6 位小数显示所有 Q16 参数，保证最小非零积分增益 `KI Q16=1`（网页显示 `0.000015`）读取后再次保存仍保持为 1。旧版网页只保留 4 位小数，修改最大占空比等其他参数时可能把这种极小 KI 显示并写回成 0；其典型现象是目标速度不为零、实际速度为零、输出停在约 2% 而不再增加。遇到该情况时，在新版网页中把对应通道 KI 恢复为 `0.000015` 并保存。

## 车载平衡滚球

滚球页面只标定摆杆左右端点、控制取球 ROI、位置 PID、结构限位和通信超时，不提供曝光、
检测阈值或钢球半径调节。K230 闭环固件保持当前正常工作的 GC2093 视觉基线；只有控制 ROI
内恰好一条无丢失标记的稳定轨迹才进入控制。网页租约、视觉、QDrive 反馈、球速、电流或
协议任一超限都会触发失能或故障锁存。

候选策略只作为有界残差叠加在基线 PID 上，单次回合限制为 1 至 20 秒。K230 是 QDrive 的
唯一控制仲裁者；网页不直接向 QD4310 发帧，也不会在未连接设备时生成训练或遥测数据。

## 本地开发

为新固件版本增加命令、遥测、参数、升级能力或新产品页面前，先阅读
[`docs/AGENT_DEVELOPMENT_GUIDE.md`](docs/AGENT_DEVELOPMENT_GUIDE.md)。该手册汇总了产品边界、
协议扩展、Flash 迁移、串口所有权、UART BSL、跨模块同步清单、测试矩阵和零上下文 Agent
任务模板。

不要直接双击 `index.html`。在本目录启动静态 HTTP 服务，再用 Chrome 或 Edge 打开本机地址：

```powershell
python .\serve_web.py --port 8765
```

然后访问 <http://127.0.0.1:8765/>。`serve_web.py` 只负责给 JavaScript 模块返回正确的 MIME 类型；仓库不依赖前端构建工具，GitHub Pages 发布内容仍是浏览器直接加载的 HTML、CSS 和 JavaScript 模块。

## 发布边界

本仓库只发布静态上位机，不包含任何 MSPM0G3507 可烧录映像、XDS110 恢复文件、NONMAIN 配置或真实板卡日志。网页协议和升级逻辑已经过主机自动测试；CHAS 页面已验证只接受 CHAS 镜像并拒绝 CM4M 镜像，CM4M 页面也会拒绝 CHAS 镜像。UART BSL 核心已在 CHAS 天猛星控制板上完成从 v1.0.0 到 v1.0.1 的实机升级、CRC 和重启版本核对。浏览器首次选择串口仍需人工授权；电机方向、编码器极性、带载闭环和整机电磁兼容仍需在具体硬件上验证。
